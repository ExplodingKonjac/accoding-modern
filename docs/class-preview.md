# 班级功能 · 1.6.0

本版本由审核通过的 local.2 转为正式版，恢复 GitHub 脚本自动更新地址。已有本地班级继续保留。

## 界面与代码查看

删除班级页面的解释性段落、重复统计说明和提交信息长描述；保留必要控件、图例及错误提示。提交列表新增“查看代码”，通过原站 `/submission/:id` 在新标签页打开对应代码页面，班级列表保持原位置。

## 使用

OJ 右下角“▦ 班级” → 导入 XLSX → 选择工作表、预览并创建 → 选择比赛 → 读取比赛 → 逐题人数 / 学生列表 / 查看提交。

支持多个班级、搜索、分页、重命名、删除本地班级和导出名册 CSV。CSV 供备份阅读，导入暂仅支持 XLSX。读取比赛和提交各有手动刷新，避免后台持续下载整场提交记录。

## 数据与接口

- 浏览器本地解析 OOXML ZIP：支持 shared strings、inline strings、缓存公式值和多工作表。自动寻找学号和姓名表头；保留文本学号中的前导零，不执行公式。数字单元格读取原始值，不模拟 Excel 自定义数字格式。
- 仅保存学号、姓名和班级，localStorage 键为 `accoding-modern.classes.v1`；不导入电话等其他信息，不把名册写入 OJ 后端。清理站点数据前保留原 XLSX。
- `GET /contest/index` 提取可见比赛链接；列表未出现的比赛可输入 ID，权限仍由服务端校验。
- `GET /api/contests/:id` 读取题序，沿用原站 rankKey 映射。
- `GET /api/contests/server_time` 判断比赛状态；未开始时不读取榜单、不显示柱形统计。
- `GET /api/contests/:id/rank` 支持原站 JSON 字符串嵌套，用 `row.user.student_id` 精确匹配学号，`row.user.id` 关联提交。不会按姓名猜测。重复账号学号单独提示并排除。
- `GET /api/contests/:id/submissions?latest=0` 依据原站 `/contest-ng/factory.js` 的初次读取方式加载本场可见记录。班级内账号筛选后仅在内存缓存元信息；不保存代码和测试点明细。切换班级 / 比赛后清除缓存，取消旧请求。
- 通过人数按 `detail.result === 'AC'`；尝试人数按非空明细；待评测算尝试。每个学生每道题最多计一次。柱长以全班人数为上限。

未匹配不等于未提交：可能尚未参赛、账号学号不一致或权限 / 封榜限制。第一版不聚合比赛外练习，也不推断不可见记录。

本机实测教务 XLSX 的表头位于第 5 行、141 人；比赛 1299 中按学号匹配 140 人，未找到 1 人、冲突 0 人。已核对提交 AC / WA 筛选、141 人分页、刷新后名册保留，10 题统计与直接读取榜单独立计算一致；浏览器模拟未开赛不读榜 / 不显示统计，403 权限错误显示错误而非零人数。名册与包含个人信息的验收截图不进入仓库；截图命名 `local-*.png` 并由 `.gitignore` 排除。
