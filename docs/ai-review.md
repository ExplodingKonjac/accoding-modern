# 页内代码复核 1.14.1

在班级页读取比赛后打开“代码复核”，自动读取最新的 API Agent（v4）运行；不再显示方案或运行选择框。列表按当前班级已匹配的 OJ 用户、比赛、题目和标签筛选，每页30条；打开列表不下载全场提交元数据，也不启动模型。

API Agent 详情提供每份目标的 `ai_suspected`、`reason`、`label`。列表只显示 `true`；其含义是检出了约定特征。标签共九类，包括输入防护、讲解／编号／对答注释、模板化说明、注释密集、生成残留以及180秒内的大幅改写和码风突变。类别可能漏项，仍可查看原码及具体理由核验。

完成、命中、未命中、失败、待处理分别显示。进度属于最新整场运行；列表属于当前班级。空列表或某份提交没有公开结果不代表它已经被判为 false。新旧运行之间的数据不会合并。

详情中的上下文源码只在点击后从已登录 OJ 读取，并核对保存的源码哈希；原站数据不匹配会显示错误。公共服务保存正例自身源码和必要证据，普通上下文留在 Mac，不随结果上传。人工记录保存在当前浏览器，绑定运行、提交和源码哈希，可随筛选结果导出。

提交源码页也有“代码复核”按钮。API Agent 使用独立 `/oj-review-api/v4`，浏览器无需令牌即可查看公开结果。运行、暂停与恢复由本机签名队列控制，页面刷新不会启动实验。

新版 v4 展示远端实际模型、请求模型、思考等级、共享调用 ID 及独立运行进度。`feature-presence-if-only-v2` 的输入防护仅限 if 检查读入状态，while/for 不定组输入循环本身不计入。候选每用户最多 4 份、后五题抽样 150 对由本机 Agent 冻结执行；插件只读取对应运行，不在浏览器重新判定或抽样。v4 公开查询不需要令牌，已移除复核设置中的令牌输入；发布和修改仍需要本机签名。
