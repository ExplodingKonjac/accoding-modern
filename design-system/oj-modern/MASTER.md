# OJ Modern 工作台

前端沿用原生 JavaScript 用户脚本、Bootstrap 原站与 Angular 比赛页。保留原节点、表单、链接、权限核验和数据模块。

设计依据：ui-ux-pro-max 的 `admin dashboard sidebar` 检索中 Minimalism & Swiss Style，采用网格、清晰层级和短交互。检索中的落地页转化区块不适用于 OJ，本项目按教学操作台组织内容。

- 页面：浅灰 `#F6F8FA`；内容：白色；分隔线：`#DFE5EB`。
- 正文：`#182536`；次要信息：`#59697B`；操作：`#275AD6`；通过：`#16765D`；错误：`#AA3047`。
- 系统中文字体，代码与数字使用系统等宽字体，不增加外部字体依赖。
- 左侧导航 236px；班级工作区侧栏 244px；内容留白 24–32px；卡片圆角 8–10px。
- header：当前班级、班级管理、设置。设置包含恢复原版、版本和检查更新。
- 左侧：比赛导航、榜单、统计看板、补题操作；班级内比赛选择、统计、补题榜和代码复核。
- 全屏看板保留暗色投屏界面，入口放在侧栏。全屏宿主留在 body，避免侧栏层叠影响。
- 班级名册操作折叠进「名册管理」；更新消息使用页内区域。
- 窄屏按文档流排列，宽表局部滚动；导航、按钮和输入有焦点指示。减少动态效果设置覆盖转场和动画。
- UI 只写操作、状态、规则和错误恢复信息；不添加装饰性标语。

样式入口为 `src/workspace.css`；共享布局和 Shadow DOM 适配为 `src/workspace.js`。

代码复核与独立提交页共用 `src/review.css`：筛选字段显示标签，详情以源码对照为主区、人工结论与辅助信息为侧区；窄屏转为纵向排列。独立提交页沿用工作台侧栏和 header。
